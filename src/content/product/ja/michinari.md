## こんなことに困っていませんか

- 立てた勉強計画が、数日でずれて使い物にならなくなる
- 遅れを取り戻す計画を立て直すのが面倒で、そのまま放置してしまう
- せっかく覚えた用語を、試験当日には思い出せない
- 本を読んでも内容を忘れてしまい、読んだ時間が積み上がった実感がない
- 月末の業務報告や半期の評価シートを前に、「今期なにをしたか」を思い出せない

**ミチナリ** は、こうした「記録し続けること」と「振り返ること」の負担を肩代わりするWindows向けの無料アプリです。インストール不要で、ダウンロードした実行ファイルを起動するだけで使い始められます。

名前は、カーナビの「道なりに進んでください」に由来します。示された道をたどるだけで目的地にたどり着けること、そして状況が変わればその都度、道が引き直されること。その両方を意味しています。作った理由やこめた思いは [『ミチナリ』を作った理由](/HomePage/ja/blog/20260831-michinari-story/) に書いています。

## 3つの目標タイプを、1つのアプリで

登録する目標には3つの種類があり、種類ごとに画面の中身が切り替わります。性質の違う取り組みを、1つのアプリで並行して管理できます。

### 資格試験 — 計画を自動で引き直す

試験日と使う教材を登録すると、**今日やるべき分量** を毎日自動で計算します。

- 進みが遅れても翌日に上乗せせず、残りの量と日数から負荷をならして配り直す
- 「予定より遅れています」と気づいた時点で警告を出し、計画の立て直しを促す
- 勉強しない日（予備日）をあらかじめ決めておける。決めた休みは「サボり」として扱われない
- 試験のあとに合否と得点を登録すると、AIが日々の記録をさかのぼって**合否の要因**を分析
- 覚えておきたい用語は**単語帳**に登録（Excel等からの一括貼り付けも可）。カードめくり・入力式・4択の3形式で、自分のタイミングで出題して理解度を確認できる

遅れても計画が崩れない仕組みは [ミチナリの資格試験プランが「上乗せしない」理由](/HomePage/ja/blog/20260903-michinari-adaptive-study-plan/) で詳しく書いています。

### 読書 — 読んだ内容を、自分の資産にする

本を1冊登録し、その日読んだ内容を思い出しながら書き留めます。

- 現在ページの入力は任意。「今日はここまで読んだ」という短い記録だけでも続けられる
- ノルマや達成率のプレッシャーはかけない。書いた内容にAIが応答し、過去の記録とのつながりを示す
- 読み終えたときに、本の要約と「何を感じ、何に気づいたか」をまとめた**読了レポート**を作れる
- 読み終えた本・途中でやめた本は**本棚**に並び、その本の記録と読了レポートをまとめて見返せる

ノルマなしでも記録が資産になる理由は [ミチナリが「ノルマなし」で記録を資産に変える仕組み](/HomePage/ja/blog/20260906-michinari-reading-as-asset/) をご覧ください。

### 仕事 — 報告書と評価シートの下書きを作る

案件（プロジェクト）を1件登録し、その日の業務内容を文章で書き留めます。

- 決まった入力欄はなく、文章で書くだけ。毎日の記録にAIが努力を言葉にして返す
- 溜まった記録から**月次報告の下書き**（要約・今月の目標・達成度評価・振り返り・来月の目標案）や**半期評価の下書き**を作れる
- 生成された内容はそのまま使わず、**必ず自分で確認・修正**できる作りになっている。提出フォームへの自動送信は行わない
- 案件ごとに**チームメンバー**を登録でき、評価者に設定すれば、日々の記録とAIフィードバックの履歴から**AI評価レポート**の下書きも作れる（メンバーの機微な情報は本人確認済みの場合のみ登録可能）

AIに下書きを任せつつ最終判断を自分の手元に残す設計は [ミチナリが自動送信をしない理由](/HomePage/ja/blog/20260909-michinari-report-draft-generation/) にまとめています。

## すべての目標タイプに共通する機能

| 機能 | できること |
| --- | --- |
| ホーム画面 | 起動すると、今日やること・進み具合・注意すべきことがひと目でわかる |
| カレンダー | 月ごとに、記録した日・予備日・試験日などを色分けして見られる |
| 日々の記録 | その日の実績を記録し、AIと対話しながら振り返れる。何もしなかった日も1タップで記録済みにできる |
| 復習クイズ（資格・読書） | 記録と単語帳からAIがクイズを作り、間隔を空けて出題。ホーム画面に「今日の復習」として数問届く |
| 節目のお祝い | 連続記録日数・読了冊数・資格の進捗率などが節目に届くと、キャラクターと一緒にお祝いする演出が表示される |
| 分析 | 記録の積み上がりをグラフや一覧で確認できる（表示内容は目標の種類ごとに変わる） |
| 記録の書き出し | 学んだ内容を読みやすい文書として書き出せる。個人的な事情を伏せて他の人に共有することもできる |
| データ管理 | 記録の一括保存・復元ができる |

## AI機能とプライバシー

日々のフィードバック、計画の見直し提案、合否の要因分析、読了レポート、報告書の下書き。これらのAI機能は社内で使えるAI基盤「NewtonX」への接続設定をすると使えるようになりますが、設定しなくても記録・閲覧・カレンダー・分析・単語帳・復習クイズといった基本機能はそのまま使えます。

記録は**PC内だけに保存**され、外部サーバーへ送信されることはありません。インターネット接続が必要になるのは、AI機能を使うときだけです。

## 今すぐ使ってみる（3ステップ）

エンジニアでなくても、3ステップで数分以内に使い始められます。

1. **ダウンロード** — [リリース一覧](https://github.com/teppei19980914/Michinari/releases/latest) を開き、最新版の `Michinari-v◯.◯.◯.zip` をダウンロードします
2. **解凍** — ダウンロードしたzipファイルを右クリックし、「すべて展開」で好きな場所に解凍します（`Michinari` フォルダができます）
3. **起動** — `Michinari` フォルダの中の **`Michinari.exe`** をダブルクリックします

数秒でブラウザが自動的に開き、アプリの画面が表示されます。アプリ本体は画面右下の通知領域（時計の左側）で待機します。初回は何も登録されていないため、読書・仕事・資格の3つから選ぶウェルカム画面が表示されます。

<details>
<summary>うまく開かないときは</summary>

- **ブラウザが自動で開かない場合**: ブラウザのアドレス欄に `http://127.0.0.1:8100` と入力してアクセスしてください
- **「WindowsによってPCが保護されました」と表示される場合**: 個人が作成したアプリのため、Windowsが警告を出すことがあります。内容を確認のうえ「詳細情報」→「実行」を選ぶと起動できます
- **通知領域にアイコンが見当たらない場合**: 通知領域の「^」ボタンを押すと、隠れているアイコンが表示されます

</details>

インストーラは不要で、アンインストールも `Michinari` フォルダを削除するだけです。操作方法は配布フォルダ内の `ユーザ手順書.pdf`、またはアプリ内の「ヘルプ」画面にまとまっています。

## 安心してお使いいただくために

- **記録はあなたのPCの中だけに保存されます。** 外部のサーバーへ送られることはありません
- **インターネット接続は不要です。** AI機能を使うときだけ通信します
- 動作環境は **Windows** です。ブラウザは Chrome / Edge などの最新版をお使いください
- 新しいバージョンへの入れ替えも、古いフォルダを新しいものに置き換えて起動するだけ。これまでの記録はそのまま引き継がれます
