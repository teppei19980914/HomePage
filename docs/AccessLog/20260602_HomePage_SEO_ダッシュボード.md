## 主要な気づき

### 良い変化
1. **平均順位が 26.85 → 5.18 に激改善** — 検索結果1ページ目前半に定着。リダイレクト対応で 404/低順位の旧 URL が整理され、純度が上がった。
2. **CTR が 9.15% → 15.83%（+73%）** — ブランド指名・プロダクトページの高 CTR（defrago 60.87%、yumehashi-story 52%、tasukiba-user 57.14%）が牽引。
3. **「ユメハシ」がブランド指名第2の柱に成長** — 0→13 クリック。ブランド SEO が機能する証明。
4. **defrago が安定的に最大の集客源** — 28 クリック（全体の 47%）、順位 2.39。

### 課題
1. **🔴 表示回数（集客の入口）が 1 日あたり 31% 減** — 5月に 40 本以上の新記事を公開したのに表示は増えていない。新記事（書籍要約・哲学・Claude プロンプト連載）が**検索表示を獲得できていない**。
2. **🟠 トラフィックが 2 ブランドクエリに集中（リスク）** — defrago / ユメハシ依存。どちらかが落ちると全体が崩れる。
3. **🟠 高表示・低 CTR ページが放置** — `/ja/product/`（54表示・9.26%・順位3.7）、`/ja/blog/`（33表示・6%）、`/ja/blog/20260410-ai-driven-development/`（28表示・7%・順位5.8）、`/ja/blog/20260417-about-me-guide/`（11表示・**CTR 0%**・順位4.55）。
4. **🟠 英語ページがほぼ 0 クリック** — en/profile 18表示0クリック、en/product/tasukiba-user 順位 28.09 が平均順位を引き下げ。
5. **ブログ記事の検索流入はほぼ無し** — janets-law-time 9表示0クリック、reading-and-perspective 5表示0クリックなど。コンテンツ量は検索集客につながっていない。

## 6 月の SEO 対策 — テーマ:「順位を保ちつつ CTR を爆発させる」

### 軸1: Average Position を持続的に向上・維持する

| 施策 | 内容 | 期待効果 |
|---|---|---|
| ①ノイズ順位の除去 | `/en/product/tasukiba-user/`（順位28.09）等、極端に低い英語ページの内容拡充 or noindex 検討。残存する旧ロケール無し URL の再クロール促進（Search Console で URL 検査→インデックス登録リクエスト） | 平均順位の下振れ要因を排除 |
| ②ブランド資産の防衛 | defrago / ユメハシ / たすきば の各プロダクトページを継続更新（更新頻度は順位維持に寄与）。たすきば連載（毎日公開中）でブランド面を厚くする | 主力2クエリの順位 2〜4 位を死守 |
| ③低ランク量産の抑制 | 検索意図の薄い記事の量産は平均順位を希釈する。**「公開すれば順位母数が増える」は逆効果**。検索で勝てるテーマ（後述）に絞る | 5.18 の純度を維持 |

**CTR 改善の共通原則（2026 ベストプラクティス）**
- タイトル: 50〜60文字、**重要語・数値・固有名を前方配置**（モバイル見切れ対策）。年号・「完全」「実績」等のパワーワード。
- description: 140〜160文字、`主要キーワード + 明確な価値 + 控えめな CTA`。ページごとに固有の文（テンプレ流用は不可）。
- **AI Overviews 対策**: description は AI 回答の citation 補足文として引用される。**「このページで何が分かるか」を一文で明示**すると AI 検索からの被引用クリックが増える。
- 効果は GSC で 30〜60 日で計測可能。**1ページずつ変えて効果を測る**（同時多変更は因果が不明になる）。

### 軸3: 表示回数の縮小トレンドへの対応（中期）
- ブランド2クエリ依存を**第3の指名クエリ「たすきば」へ拡張**（連載で認知形成 → 6月計測）。
- 検索で勝てる**ロングテール実績クエリ**（「テスト 工数 削減」「ユニットテスト 自動化」等、本人の実績直結語）を**記事タイトルに含める**形でリライト/新規化。書籍要約・哲学系は検索集客では勝ちにくい（飽和市場）ため、Qiita 等の別チャネルへ。

## 市場トレンド・SEO 環境分析（2026年）

- **ゼロクリック検索が常態化** — 米国 Google 検索の約 60% がクリックなしで完結。AI Overviews 表示クエリでは **83%** がゼロクリック。情報系クエリの「表示はされるがクリックされない」は構造的。当サイトの**表示減・CTR増**はこの環境変化と整合する。
- **AI Overviews による CTR 影響** — 1位の CTR を最大 58% 押し下げる調査結果。一方、**生き残ったクリックは 23% 高コンバージョン**。「広く薄く」より「狭く濃く（ブランド・高インテント）」が有利 → 当サイトの現状の強み（ブランド指名・プロダクトページ）と一致。
- **AI Overview への被引用が新たな勝ち筋** — 引用されたブランドは非引用比 **+35% CTR**。順位だけでなく「AI回答内に出るか」が重要に（GEO / AEO）。
- **E-E-A-T が AI の信頼フィルタに** — 一次情報・実体験・固有実績（当サイトの defrago/ユメハシ/たすきば 実運用、開発実績数値）は AI 検索でも評価されやすい強み。
- **示唆**: 当サイトの方向性（ブランド集中・実体験ベース・高 CTR）は 2026 トレンドに合致。**表示母数の縮小は悲観材料ではなく、むしろ高純度化**。ただし入口が細るリスクには、ブランドクエリの数を増やす（第3・第4の指名語）ことで対応する。
