### 課題

1. **⚠️ ロケール無し旧 URL が 404 を返している（重要）** — `/HomePage/profile/`, `/product/`, `/contact/`, `/blog/`, `/project/` は i18n 移行前の URL 構造で、合計 **121 表示 / 9 クリック** が発生中だが、現サイトには対応するページが存在せず **404**。クリックしたユーザーが離脱、Google も評価を下げる方向
2. **`/HomePage/ja/profile/` は 28 表示で 0 クリック（CTR 0%）** — 順位 14.61 は悪くないが、検索結果での魅力が不足。description 最適化（本セッションで対応済み）の効果は今後計測
3. **「ジャネーの法則」順位 3 で 0 クリック** — 該当記事の検索結果見出し / description が、このクエリのインテントとマッチしていない可能性
4. **英語ページの絶対量が少ない** — en/profile 8 表示 1 クリック、en/blog/* は 0 クリック。コンテンツ量・流入経路ともに不足
5. **ブランド指名が「defrago」のみ** — 「ユメハシ」(2 表示)、「たすきば」(1 表示) は認知途上。プロダクト名のブランド SEO に余地

## 5 月の SEO 対策・全体方針

### 最優先（今週中）

#### 1. 旧ロケール無し URL への 301 リダイレクト追加
`astro.config.mjs` の `redirects` に以下を追加し、404 を救済する:

```js
"/profile/": "/HomePage/ja/profile/",
"/product/": "/HomePage/ja/product/",
"/contact/": "/HomePage/ja/contact/",
"/blog/": "/HomePage/ja/blog/",
"/project/": "/HomePage/ja/project/",
```

→ 推定 9 クリック / 月 + 121 表示 / 月のロスを止める。Google にも canonical を伝達できる。

#### 2. 「ジャネーの法則」記事の検索スニペット最適化
- `20260413-janets-law-time.md` の title / description を「ジャネーの法則 対策」「ジャネーの法則」のクエリインテントに合わせて調整
- 順位 3 のクエリで CTR が 0% という現状は、**title/description のクリック誘発力に課題** がある可能性が高い

### 高優先（5 月中）

#### 4. ピックアップ記事の検証

- 「teppei」（10 表示 0 クリック）「teppei nishiyama」（1 表示）など人名検索の受け皿として機能するかを 6 月計測

#### 5. 「ホームページを開設しました」クエリへの追従
- 22 + 15 = **37 表示 / 5 クリック** で 13% CTR の有力クエリ
- 該当記事 [`20260406-hello-world.md`](/HomePage/ja/blog/20260406-hello-world/) の引用 / 関連記事リンクを強化し、関連クエリ（「個人ホームページ 作り方」など）への横展開を検討

### 中優先（5〜6 月）

#### 6. 英語版コンテンツの強化
- en/profile 平均順位 6.63 で 1 クリック → 順位は十分に高い、量を増やせばスケール
- product コンテンツの英語版が現状未整備（`src/content/product/en/` が存在しない）→ 整備を検討

#### 7. ロングテール 0 クリッククエリへの対応
- 「テスト 工数 削減」(順位 27)、「ユニットテスト 自動化」(順位 34)、「手動テスト」(順位 37) など、本人の実績と直結するクエリで表示中
- これらのクエリをタイトルに含む形での記事化（実績の事例ベース解説など）を検討

### 全体方針

5 月は **「拡大より定着」** を方針とする。

- 4 月のベースラインから 5 倍のトラフィック増を達成。各メトリクスは順調
- ただし **404 となっている旧 URL の救済**、**順位上位なのに CTR 0% のページ**（ja/profile, ジャネーの法則）の改善が、現状の伸びを定着させるための鍵
- 新規記事の量産より、**既存記事の検索体験（title / description / 内部リンク）品質向上** に重きを置く
- 6 月時点で「クリック 100 / 月」を目標とする（現在の伸び率を維持できれば達成可能）
